Privacy Policy: Canais Dark Metricas

Last updated: October 19, 2026.

Canais Dark Metricas is a personal tool used only by its owner to read analytics of the owner's own YouTube channels.

Data accessed

With the account holder's permission, the tool reads YouTube channel and video metadata and YouTube Analytics reports through the YouTube Data API and YouTube Analytics API, using read-only scopes.

How data is used and stored

Data is used only to produce performance notes for the owner. Authorization tokens and reports are stored only on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Local data is deleted on request or when the tool is removed.
